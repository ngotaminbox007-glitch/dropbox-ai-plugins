# Shared Material

This directory contains reference material shared by the Claude, Codex, Google Antigravity, and Cursor artifacts.

- `OAUTH_SCOPES.md` documents the Dropbox OAuth scopes used by the Codex, Claude, Google Antigravity, and Cursor MCP plugin artifacts.
- `SKILL_REFERENCE.md` documents skill inputs, outputs, and usage examples for all Dropbox host skills.
